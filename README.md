## 这是什么

备考最烦的不是没有资料，是资料太散：真题一份、刷题本一份、系统班一份、专项一份，散落在几十个分享链接里，每次想找都要重新翻聊天记录。

这个资料库把它们收成一个入口，按考试类型和科目分好类，并且**每天自动同步更新**——上游有新内容时，链接不变，打开就是最新版。

## 怎么用

1. 打开上面的飞书文档。
2. `Ctrl + F` 搜你要的年份、科目或省份（比如「申论」「综应A」「广东」）。
3. 点开夸克网盘链接，选择「保存到网盘」。
4. 建议优先转存两个覆盖面最大的：**2027 国省考资料合集** 和 **全家桶笔记**，其余按自己的弱项补。

## 适合谁

- 准备 2027 国考、省考，还在东拼西凑资料的人
- 备考事业单位联考，需要按 ABCDE 类别或所在省份找资料的人
- 想要一份「收藏一次、自动更新」的固定入口，而不是每天追更的人
